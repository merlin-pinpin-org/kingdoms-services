class GameData(builtins.object)
    Game data service (direction développeur, architecture cible):
one process per game (game-aoe2), the ONLY consumer of the external
providers (ext-librematch, ext-aoe2lobby, ...) for that game. It owns
the game domain tables (matches, players, stats), exploits the raw
provider data, and serves the consolidated state to svc-core and the
bot. svc-core never talks to the providers, and vice versa.
 
The contract is game-generic: the game is a parameter, so a future
game-aoe4 process serves the same contract with game_key = "aoe4".

  Methods defined here:
GetCoverage(self, request, context)
Declare which games this service covers and per-game capabilities.
GetProviderTests(self, request, context)
The providers' health-test results for a game: the game service
probes its providers periodically (capabilities ping, live stream
liveness) and serves the last results per provider.
UpdateEnrollments(self, request, context)
Push the platform's enrolled profile ids for a game. The service
reconciles its providers' subscriptions in place (no teardown).
WatchDashboard(self, request, context)
Server-stream the live dashboard state for a game: linked players,
their status (in_lobby/in_game), and the enriched match summary
(map, civilization, format, join/spectate links).
WatchPlayerEvents(self, request, context)
Server-stream player status transitions for a game (the generic
mod-notification feed): each transition carries the full match
summary so mods render rich notifications without extra calls.
