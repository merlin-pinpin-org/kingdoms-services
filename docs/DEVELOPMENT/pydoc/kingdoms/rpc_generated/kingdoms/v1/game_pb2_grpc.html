class GameServicer(builtins.object)
    Game provider service (ADR-0020): an external game data provider process
(ext-librematch, ext-aoe2lobby, ...) serves this contract to svc-core.
The core never interprets provider-internal identifiers: match_ref,
profile_id and faction_key are opaque strings at the contract level.
 
  Methods defined here:
GetCapabilities(self, request, context)
Declare what this provider actually supports. The core degrades
cleanly on anything absent (reference: ladder spec 1.2).
GetMatchDetails(self, request, context)
Full match details: map, slotinfo (per-slot state) and the raw
game options (map size, speed, victory condition, ...).
GetMatchLinks(self, request, context)
Game action links (join/spectate/insights) as opaque label+url pairs.
GetMatchResult(self, request, context)
Fetch the result of a finished game (winner, duration, map, factions).
GetPlayerStats(self, request, context)
Named stats blocks for a player profile (rendered by the platform
adapter; the core never formats them).
ListMaps(self, request, context)
The maps this provider knows about for its game (catalog data).
ResolveProfile(self, request, context)
Resolve which mod user matches a game profile. Used for profile
validation at registration and for match participant resolution.
StreamMatchEvents(self, request, context)
Stream match lifecycle events (lobby_opened, lobby_closed,
game_started, game_ended) for the matches this provider can see.
