class Content(builtins.object)
    Game content provider service (ext-aoe2techtree family): a content
source process serves localized game catalog data (factions, maps) to
svc-core. Content is immutable between game patches; the core caches it
in Mongo/Redis and bot admins trigger a refresh on patch days. The
upstream the ext process reads (vendored dataset, HTTP API, ...) is
the provider's own concern — the core only ever sees this contract,
so switching to another API source never touches the consumers.
