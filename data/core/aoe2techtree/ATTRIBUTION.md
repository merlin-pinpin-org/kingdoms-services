# AoE2 game data attribution

The data files in this directory (`data.json`, `strings-*.json`) are
extracted from the open-source **aoe2techtree** project
(https://github.com/SiegeEngineers/aoe2techtree), MIT licence
© 2018 HSZemi, which itself extracts the game data from Age of
Empires II: Definitive Edition.
